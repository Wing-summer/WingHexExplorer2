# 界面文案与翻译 / UI text and translation

英文原文及 `lang/builtin` 文档内置，仅维护 `lang/zh_CN`、`lang/zh_TW` 翻译。`en_US` 表示英文，空设置跟随系统；语言不匹配或资源缺失、损坏时回退英文并记录日志。保留插件独立翻译机制。

English source text and `lang/builtin` documents are built in. Maintain only `lang/zh_CN` and `lang/zh_TW`. `en_US` selects English; an empty setting follows the system. Unsupported locales or missing/invalid resources fall back to English with diagnostics. Preserve independent plugin translation.

## 文案规则 / Writing rules

- 使用自然英文和句首大写，如 `Save selection`；保留 Qt、UTF-8、JSON 等正式名称，避免 `SaveSel` 一类内部缩写。
  Use natural English and sentence case, such as `Save selection`. Preserve official names such as Qt, UTF-8, and JSON; avoid internal abbreviations such as `SaveSel`.
- 按钮使用短动作标签，完整说明放入可翻译提示；无障碍名称对应标签，描述对应说明。普通文本插入 HTML 前须转义。
  Use short action labels and translatable explanatory tooltips. Accessible names follow labels; descriptions follow explanations. Escape plain text before inserting it into HTML.
- 按实际字体和布局检查长度，优先精简文字，再调整局部尺寸或换行。`...` 用于后续输入、选择或进行中状态，不用于隐藏关键文字。
  Check length with actual fonts and layouts. Shorten wording before adjusting local sizing or wrapping. Use `...` for further input, selection, or progress, never to hide essential text.
- 错误使用完整句子，原因确定时再提供解决建议。整句翻译，以 `%1` 等占位符插入变量，避免拼接译文。
  Write errors as complete sentences and suggest remedies only for known causes. Translate whole messages with placeholders such as `%1`, rather than joining translated fragments.
- 使用适当的 `tr()` 上下文；同文异义使用 `tr("text", "disambiguation")`，特殊含义用 `//:` 注释说明。显示文字调整不得改变内部名称、配置键、插件 ID 或脚本 API。
  Use the appropriate `tr()` context, `tr("text", "disambiguation")` for distinct meanings, and `//:` comments for special context. Display-text changes must preserve internal names, settings keys, plugin IDs, and script APIs.

The Markers group contains bookmarks and annotations. Use Annotation (标注／標註) for region colors and comments; internal data structures retain the name metadata. Keep the status labels `STR/HEX` and script information values `true/false` unchanged.

## 更新与验证 / Updating and validation

在项目根目录运行，Qt 工具使用本地安装路径；测试工具通过 CMake 自动发现，也可用 `--lrelease` 覆盖：

Run from the project root using locally installed Qt tools. Tests discover tools through CMake; `--lrelease` overrides that tool:

```sh
lupdate src 3rdparty/QConsoleWidget 3rdparty/QHexView \
  3rdparty/Qt-Advanced-Docking-System/src 3rdparty/QWingRibbon \
  -no-obsolete -ts lang/zh_CN/winghex_zh_CN.ts lang/zh_TW/winghex_zh_TW.ts
python3 tools/check_translations.py
python3 tests/i18n/run.py --build-dir /tmp/wing-i18n-tests
```

人工审核新增及模糊匹配译文后再清除 `unfinished`。检查器验证消息覆盖、目录一致性、空译文、占位符、快捷键标记、文件过滤器及 UI 文件；品牌例外集中维护。

Review new and fuzzy-matched translations before clearing `unfinished`. The checker verifies message coverage, catalog consistency, empty translations, placeholders, mnemonic markers, file filters, and UI files. Maintain brand exceptions centrally.

独立测试覆盖语言回退、插件翻译、脚本元数据及三语言下 100%/150%/200% 缩放的布局尺寸；完整应用仍须人工检查动态 Ribbon、菜单及原生控件。

Standalone tests cover language fallback, plugin translation, script metadata, and layout sizing in three languages at 100%, 150%, and 200% scaling. Manually inspect dynamic Ribbon controls, menus, and native widgets in the full application.
